# WIZO Israel — Institution Map 2026

## איך להעלות ל-GitHub Pages (5 דקות)

### שלב 1 — צור חשבון GitHub
כנסי ל-[github.com](https://github.com) וצרי חשבון חינמי

### שלב 2 — צור Repository
1. לחצי על **"New"** (ירוק, למעלה)
2. Repository name: `wizo-map`
3. סמני **Public**
4. לחצי **Create repository**

### שלב 3 — העלי את הקובץ
1. לחצי **"uploading an existing file"**
2. גרורי את הקובץ `index.html` לתוך החלון
3. לחצי **"Commit changes"**

### שלב 4 — הפעל GitHub Pages
1. לכי ל-**Settings** של ה-repository
2. בתפריט שמאל: **Pages**
3. תחת Source: בחרי **Deploy from a branch**
4. Branch: **main** → folder: **/ (root)**
5. לחצי **Save**

### שלב 5 — קבלי את הקישור
אחרי כ-2 דקות, הקישור שלך יהיה:
`https://YOUR-USERNAME.github.io/wizo-map/`

### קישורים לפדרציות
כל פדרציה מקבלת קישור מותאם:
- UK: `https://YOUR-USERNAME.github.io/wizo-map/?federation=UK`
